# React Food Recipes 🍽️

A modern and responsive recipe web application built using React and Vite. Users can browse recipes, explore categories, search meals, save favorites, and view detailed recipe information with ingredients and cooking instructions.

---

## 🚀 Live Features

- 🏠 Home Page
- 🍲 Browse Recipes
- 🔍 Search Recipes
- 📂 Explore Categories
- ❤️ Add & Remove Favorites
- 📖 Detailed Recipe Page
- 📑 Pagination
- 📄 About Page
- 📱 Responsive Design
- ⚡ Fast Loading with Vite

---

## 🛠️ Tech Stack

### Frontend
- React.js
- React Router DOM

- TheMealDB API

## ⚙️ Installation

Clone Repository

```bash
git clone https://github.com/your-username/react-food-recipes.git
```

Move into project

```bash
cd react-food-recipes
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```

Build project

```bash
npm run build
```

Preview build

```bash
npm run preview
```
